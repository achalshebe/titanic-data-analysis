# Titanic Data Analysis

Titanic Data Analysis using Python and Power BI to explore passenger characteristics, survival patterns, fare distribution, and demographic insights.

## Project Overview

This project analyzes the Titanic passenger dataset using Python for data cleaning and analysis and Power BI for interactive data visualization.

The objective is to understand the factors associated with passenger survival and identify meaningful patterns across gender, passenger class, age, fare, family size, and embarkation point.

## Tools & Technologies

- Python
- Pandas
- Google Colab
- Power BI Desktop
- Jupyter Notebook
- GitHub

## Data Cleaning

The dataset was cleaned and prepared for analysis by:

- Removing the Cabin column
- Handling missing Age values using the median
- Handling missing Embarked values using the mode
- Renaming columns for easier analysis
- Creating calculated fields for further analysis

## Analysis Performed

The project includes analysis of:

- Survival rate by gender
- Survival rate by passenger class
- Average fare by ticket class
- Passenger distribution by embarkation point
- Female passengers under age 18
- High-end travelers with Fare greater than 100
- Highest-paying passengers
- Passenger distribution by age
- Survival by family size
- Solo travelers
- Age and fare patterns by survival status

## Power BI Dashboard

The Power BI dashboard contains three pages:

### Page 1 – Titanic Survival Analysis Dashboard
Provides an overview of passenger count, survival, fare, ticket class, gender, and embarkation filters.

### Page 2 – Titanic Survival & Passenger Insights
Focuses on survival patterns across gender, ticket class, family size, embarkation, and solo travelers.

### Page 3 – Titanic Business Insights
Provides deeper analysis of fare, age, high-end travelers, female passengers under 18, and highest-paying passengers.

## Key Insights

The analysis highlights differences in survival patterns across passenger classes and gender, along with relationships between age, fare, family structure, and survival.

The Power BI dashboard provides an interactive way to explore these patterns using filters and visualizations.
